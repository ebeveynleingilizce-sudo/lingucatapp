# Kenney Medals — LinguCat badge assets

Original asset: Medals 1.1 by Kenney, CC0. https://kenney.nl/assets/medals

Original License.txt is preserved as LICENSE-kenney-medals.txt. Individual SVG medal viewports were extracted from Vector/medals_vector.svg in the user-supplied ../kenney_medals.zip archive. Brand gold gradients were added to selected fills; category glyphs and glow are separate CSS/SVG overlays. PNG fallbacks were rendered from these SVG derivatives at 240×480. File-level provenance is in sources.json.

The Kenney Game Icons and FreeGameUI sources were also inspected; the existing local LinguCat SVG icon system was sufficient, so no additional icon package or CDN dependency was added.

Reward sounds use the already bundled Fantasy UI SFX Free by heyheythere - https://heyheythere.itch.io/fantasy-ui-sfx-free - CC BY 4.0. Attribution and full license are in ../interaction/.
