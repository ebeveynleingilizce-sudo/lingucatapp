# English Battle Arena
LinguCat-Baslat.cmd ile uygulamayı açın. Mevcut Python kurulumu kullanılır; yeni bağımlılık yoktur. Yerel sunucu yalnız 127.0.0.1:8765 üzerinde çalışır. İnternet gerekmez. HTML dosyasına çift tıklayarak hikâye/şarkı yine kullanılabilir; Godot web oyunu HTTP gerektirir.
Oyunlar → English Battle Arena. 2–5. sınıfların İngilizce ünite havuzlarından toplam 200 soru içerir. Ders seçimi diğer dersleri göstermez. Kartlar, +6 karşı saldırı, değişken ork hamleleri, doğru/yanlış ve Devam akışı korunur. Oyunlara Dön oyunu kapatır, müziği durdurur.
Battle Arena soru geçmişi tarayıcıda ayrı tutulur. LinguCat hikâye/şarkı XP hesaplamasına savaş puanı eklenmez. Godot web sürümü WebGL2 destekleyen güncel tarayıcı gerektirir; eski akıllı tahtalarda ayrıca cihaz kontrolü gerekir.
